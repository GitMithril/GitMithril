# GitMithril — Profile README Prompt

Use this file as the **single prompt** for generating my GitHub profile README. The README must be professional, concise, and visually clean. It should be inspired by the layouts and visual balance of:
- https://github.com/SP-XD/SP-XD
- https://github.com/rahul-jha98/rahul-jha98

## Goals
- Keep it clean, readable, and professional.
- Use only **relevant** information from `details.md`.
- If any field is missing, keep a clear placeholder (do **not** invent facts).
- Avoid fluff and unrelated sections.
- Use badges from **Badges4-README.md-Profile** only when the tool/tech is relevant.

## Required Sections (in this order)
1. **Header / Hero**
   - Display name + short headline.
   - Optional short one‑line bio.
2. **About Me**
   - 3–6 bullet points based on `details.md`.
3. **Featured Projects**
   - A clean table with 3–6 projects (name, short description, link, tech if known).
4. **Tech Stack**
   - Badges only for skills/tools listed in `details.md`.
5. **GitHub Stats**
   - Use GitHub stats cards (stats + top languages).
6. **Connect**
   - Only include links that exist in `details.md`.
7. **Snake Contribution Graph**
   - Add the GitHub Snake SVG/GIF at the very bottom.

## Visual Guidance
- Prefer simple Markdown with occasional centered blocks.
- Keep image sizes modest and aligned.
- Use whitespace between sections.
